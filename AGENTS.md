# Repository instructions

Use public DSH plugin APIs. Never patch DSH or test against a live user profile. Preserve LICENSE, NOTICE, and source provenance. Use Node.js 24. Run npm ci, npm run test:prepare, npm run check, npm run test:integration, and the exact packed delivery check for Bridge changes. Keep unit, fixture, packaged delivery, production, and device evidence separate. Never commit pairing state, runtime profiles, credentials, private screenshots, or signing material. Keep the App repository's bridge/ snapshot intact. Public commits use the configured human Git identity.
